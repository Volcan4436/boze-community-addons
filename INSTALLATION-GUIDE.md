# Installation Guide
## Prerequisites
- Basic knowledge of a file manager
- Boze Client installation*
- Minecraft (duh)

*requires same minecraft version as addon

## setup
1. locate your `.minecraft` folder or wherever your boze installation is located.
2. you should see a `mods` folder. (`.minecraft/mods` is where it will be located on most machines)
3. locate your boze addon file it **should** be a `.jar` file. (if it isn't then double check if it is a `.zip` file if so extract the `.jar` to proceed with the installation using the extracted `.jar` file)
4. transfer your boze addon `.jar` file to your `mods` folder (this should be all that is required to install the addon.
5. launch boze from your launcher.
